STATE — программное обеспечение для централизованного учёта оборудования и контроля его размещения на предприятии.

Проект направлен на упрощение управления материальными ресурсами, систематизацию информации и повышение эффективности внутренних процессов.
Возможности:
1. Учёт и управление оборудованием.
2. Контроль размещения имущества.
3. Организация структуры помещений и филиалов.
4. Формирование отчётности.
5. Централизованное хранение информации.
